# alisal97.github.io

Pages for Azan Way, published with GitHub Pages:

- `/azan-way/`: app page
- `/azan-way/privacy/`: privacy policy (App Store privacy policy URL)
- `/azan-way/support/`: support and contact (App Store support URL)

Each page has English, Italian and Arabic sections (`#en`, `#it`, `#ar`). Styles are in `assets/site.css` and use the app's colours.
